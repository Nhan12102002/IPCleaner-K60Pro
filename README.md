# IP Cleaner – Redmi K60 Pro / MIUI 14

Ứng dụng Android Kotlin, không yêu cầu Root.

## Tính năng
- Kiểm tra IP Internet công khai và ghi lại lịch sử.
- Mở cài đặt mạng di động để người dùng tự tắt/bật dữ liệu.
- Mở trang thông tin ứng dụng Chrome để người dùng chọn xóa tất cả dữ liệu.
- Quy trình kết hợp hai bước và nhật ký thao tác lưu cục bộ.

## Giới hạn Android
Android không cho ứng dụng thông thường tự bật/tắt mobile data hoặc xóa dữ liệu riêng của Chrome. Vì vậy, các thao tác này cần người dùng xác nhận trong Cài đặt. Đổi kết nối không đảm bảo nhà mạng cấp IP khác. Dữ liệu đã đồng bộ trên Google hoặc máy chủ website không bị xóa khỏi máy chủ.

## Tải APK
Mỗi lần push mã nguồn lên nhánh main, GitHub Actions sẽ build APK debug và lưu thành artifact IPCleaner-debug-apk trong tab Actions.
